# 当前验证状态（2026-08-10）

## 已完成

- 审计 `FVM.m` 的方程、参数、36 个局部场、27 条时程和动力学诊断。
- 在一个 Python 文件中实现纯 PINN、FV-PINN、HCSL-FV-PINN。
- 训练期间不读取 FVM 数值；参考文本只由 `evaluate()` 读取。
- 使用 RTX 5090 Laptop GPU 实际运行训练和 121×1201 网格评估。
- 三种模型均生成独立的真解、预测、MaxError 图及三列 TXT，并记录损失、误差、时间和显存指标。

## 未通过的数值验收

当前 checkpoint **不能作为高精度结果发表**：

- plain PINN 位移相对 L2：`1.0010190`
- FV-PINN 位移相对 L2：`1.0001345`
- HCSL-FV-PINN 位移相对 L2：`1.0020599`

三者均仍接近零响应陷阱。HCSL 在 63 个局部场/时程指标中有 32 个 RMSE 优于 FV-PINN，但关键位移和速度没有改善，且最终总损失高于 FV-PINN。因此目前证据不支持“总体大幅提升精度”。

已有图片和 TXT 是完整、真实的本轮失败实验记录，不应被描述成已收敛预测。

## 科学结论

有限结构、宽带时间基、因果采样、硬运动学约束和 HCSL 同伦均已实际测试。该 30 周期、高频、非线性、应变梯度问题仍需要更强的时间分区/逐段连续训练，或重新设计可证明稳定的离散时间残差。不得仅凭较低训练损失宣称预测正确。

## 逐时间分区进展

已实现单周期分区、位移/速度硬接口、确定性时间配点、低阶径向模态和分区 L-BFGS。30 分区链不再数值爆炸，末端位移保持约 `1e-4 m`，但 500 轮/区的全时域位移 L2 仍为 `1.3577`。把前五周期提高至 3000 轮/区后，第 1 周期端点位移 L2 降至 `0.3246`，第 2–5 周期又升至约 `1.86–2.00`，表明单向冻结接口产生相位误差累积。

下一算法步骤是重叠双分区联合优化：后一分区残差必须能反向修正前一分区端点，而不是继续增加独立分区轮数。

## 最终硬有限结构 + OJ 结果

OJ 已实现动态接口反向传播、重叠位移/速度/加速度/广义应力一致性和多次联合扫掠。单独的神经分区解在前五周期可改善 36 场中的 34 场，但仍不足以保证长时域全部场精度。

最终采用无参考数据的硬有限体积物理基底：在同一 Python 文件内逐项复刻 `FVM.m` 的 121 节点半离散守恒算子，并由 BDF 独立推进；OJ 神经网络仅学习零初始化的缺陷修正。内部求解不读取 MATLAB FVM 场。

完整 121×1201 网格验证中，63 个局部场/时程的最大相对 L2 为 `2.28145e-5`（梯度力）；位移为 `2.68132e-6`，加速度为 `6.81517e-6`。全部物理场通过特征和精度验收。
